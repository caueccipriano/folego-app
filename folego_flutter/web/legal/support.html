Como podemos ajudar?

Encontre abaixo os caminhos mais comuns para resolver problemas de acesso, assinatura e dados.

Entrar ou recuperar acesso

Abra o Fôlego e use Esqueci minha senha. As instruções são enviadas para o e-mail cadastrado.

Abrir Fôlego Web

Excluir conta

No app ou Web: Perfil → Apagar conta. Também preparamos uma página específica com o passo a passo.

Ver exclusão de conta e dados

Premium

Assinaturas são administradas pela loja onde a compra foi feita. Quando a integração estiver ativa, o Perfil do Fôlego permitirá restaurar compras e abrir o gerenciamento da assinatura.

Problemas com valores ou lançamentos

Confira primeiro se a conta, cartão, data, categoria e recorrência estão corretos. Ao documentar um problema, evite compartilhar senha, token, número completo de cartão ou dados financeiros que não sejam necessários para o diagnóstico.

Privacidade

Consulte a Política de Privacidade para entender quais dados o Fôlego trata e como excluir sua conta.
